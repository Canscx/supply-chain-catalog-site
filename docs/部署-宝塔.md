# 部署到宝塔面板（完整步骤）

面向第一次部署的人。全站是**纯静态 HTML + 一个 PHP 接口**，不需要 Node 常驻、不需要数据库。

> 只看咨询表单的配置细节，见 [部署-咨询表单](部署-咨询表单.md)。本文是端到端全流程。

---

## 0. 部署前先在本机确认

```bash
cd site
npm run check     # 数据自检，必须通过
npm run build     # 产出 site/dist/
```

通过后 `site/dist/` 就是**唯一要上传的东西**，共 18 个文件、约 520KB：

```
index.html                首页
catalog.html              产品链条目录
favicon.svg  robots.txt
assets/                   5 个 CSS/JS
downloads/                2 个模板（docx / xlsx）
api/consult.php           咨询提交接口
api/leads.php             CSV 下载（带口令）
api/config.example.php    配置模板（复制成 config.php）
api/cacert.pem            企微 HTTPS 证书
api/.htaccess             Apache 防护（nginx 下无效，留着无害）
api/data/index.php        兜底 403，防止目录被浏览
api/data/.htaccess
```

---

## 1. 宝塔建站

1. 登录宝塔 → 左侧 **网站** → **添加站点**
2. 填写：
   - **域名**：`chain.peipaoclub.com`（要提前在域名商把 A 记录指到服务器 IP）
   - **根目录**：默认 `/www/wwwroot/peipaoclub.com`
   - **FTP**：不创建
   - **数据库**：不创建（本项目不用数据库）
   - **PHP 版本**：选 **PHP 7.4 或更高**（推荐 8.0/8.1）
3. 点「提交」

> 建站后宝塔会生成 `index.html`、`404.html` 和 `.user.ini`。**不要删 `.user.ini`**，它管 open_basedir。

---

## 2. 上传站点文件

### 方式 A：面板文件管理器（推荐，最直观）

1. 宝塔 → **文件** → 进入 `/www/wwwroot/peipaoclub.com`
2. **先删掉宝塔生成的默认 `index.html`**（否则会覆盖你的首页）
3. 点右上角 **上传** → 选择 `site-dist-YYYYMMDD-HHMM.zip`
4. 上传完成后，右键该 zip → **解压** → 解压到当前目录
5. 解压后确认根目录长这样：

```
/www/wwwroot/peipaoclub.com/
├── index.html          ← 你的首页（约 156KB）
├── catalog.html
├── favicon.svg
├── robots.txt
├── assets/
├── downloads/
└── api/
```

6. 删除 zip 包（**重要**，见第 8 节）

> ⚠️ 文件管理器默认**隐藏点号开头的文件**。点右上角「设置」勾选「显示隐藏文件」，确认 `api/.htaccess`、`api/data/.htaccess` 都传上来了。这两个在 nginx 下不生效，但留着不碍事。

### 方式 B：命令行 scp（更快）

```powershell
# 本机执行
scp -r site/dist/* root@你的服务器IP:/www/wwwroot/peipaoclub.com/
```

---

## 3. 创建接口配置 api/config.php

**这一步不做，提交表单会返回 503。**

1. 宝塔 → 文件 → 进入 `/www/wwwroot/peipaoclub.com/api`
2. 右键 `config.example.php` → **复制** → 粘贴，重命名为 `config.php`
3. 双击 `config.php` 编辑，填两项：

```php
<?php
return [
    'wecom_webhook' => 'https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你的key',
    'admin_token'   => '自己编一串32位以上随机字符，别用生日手机号',
    'data_dir'      => dirname(__DIR__, 2) . '/consult-data',
    'rate_limit'    => [
        'window_seconds' => 600,
        'max_per_window' => 10,
        'max_per_day'    => 50,
    ],
];
```

**企微 Webhook 怎么拿**：
1. 打开要接收通知的群 → 群设置 → 群机器人 → 添加机器人
2. 选「自定义消息推送」，名称填「链条咨询推送」
3. 复制 Webhook 地址

> 只能用手动添加的「群机器人 Webhook」。智能机器人的 Bot ID/Secret 需要 WebSocket 长连接，用不了。

---

## 4. 创建数据目录

CSV 默认写到**网站根目录之外**，防止被直接下载。

1. 宝塔 → 文件 → 进入 `/www/wwwroot`
2. **新建文件夹** `consult-data`
3. 右键 → **权限** → 设为 `755`，**所有者**设为 `www`（有「设置所有者」选项就选 www）

路径最终是 `/www/wwwroot/consult-data/consultations.csv`。

---

## 5. 放开 open_basedir（最容易踩的坑）

宝塔默认的 `open_basedir` 只允许网站根目录和 `/tmp`，而数据目录 `/www/wwwroot/consult-data` 在根目录之外，会报：

```
open_basedir restriction in effect. File(/www/wwwroot/consult-data/consultations.csv) is not within the allowed path(s)
```

> **先判断要不要做这步**：如果提交表单能成功（页面出现「提交成功」），说明这一步已经没问题，可以跳过。只有出现上面那条报错才需要改。

### 方式一：面板开关（最简单）

宝塔 → 网站 → 你的站点 → **设置** → **网站目录** → 找到「**防跨站攻击(open_basedir)**」→ **关闭** → 保存。

关掉后该站点不再受 open_basedir 限制，也就不需要手动改文件了。代价是安全性略降（同一 PHP 进程内的其他站点理论上可互相访问）。

### 方式二：手动改 .user.ini（推荐，保留防护）

**第 1 步：打开隐藏文件显示**

宝塔文件管理器**默认不显示点号开头的文件**，看不到 `.user.ini`。

文件管理器右上角 → **设置**（齿轮图标）→ 勾选「**显示隐藏文件**」。

**第 2 步：找到文件**

路径：`/www/wwwroot/peipaoclub.com/.user.ini`

> 注意：它在**网站根目录下**，不在 `api/` 里，也不在 `/www/wwwroot/` 下。

**第 3 步：编辑**

右键 `.user.ini` → **编辑**。你的原始内容是这样一行：

```ini
open_basedir=/www/wwwroot/peipaoclub.com/:/tmp/
```

把 `:/www/wwwroot/consult-data/` **追加到这一行末尾**（不要新起一行，open_basedir 只认一行）：

```ini
open_basedir=/www/wwwroot/peipaoclub.com/:/www/wwwroot/consult-data/:/tmp/
```

**改完应该是这样，注意 4 个细节：**

| 细节 | 说明 |
| --- | --- |
| **只有一行** | 不能写成多行 `open_basedir=`，PHP 只读最后一条 |
| **冒号分隔** | 每个路径前加 `:`，路径之间不能有空格 |
| **路径末尾带 `/`** | `consult-data/` 不能写成 `consult-data`。少了斜杠会变成前缀匹配，`consult-data-backup` 这类目录也会被一并放行 |
| **保留原有项** | 原来的 `/tmp/` 不要删，删了可能影响临时文件、上传等功能 |
| **插入位置** | 加在中间或末尾都可以，只要在同一行。上面示例放在中间是为了让「站点目录 → 数据目录」挨着，方便阅读 |

> 你的文件里没有 `/proc/`，这是正常的，不用补。不同宝塔版本生成的默认值不一样，以你面板里看到的为准。

**第 4 步：如果文件不存在**

在网站根目录右键 → **新建文件** → 命名 `.user.ini` → 双击编辑，写入：

```ini
open_basedir=/www/wwwroot/peipaoclub.com/:/www/wwwroot/consult-data/:/tmp/
```

**第 5 步：让改动生效（关键，很容易漏）**

PHP 会**缓存 `.user.ini` 最多 5 分钟**（`user_ini.cache_ttl` 默认 300 秒），所以改完立刻提交可能还是报错。两种做法：

- **立刻生效**：宝塔 → 软件商店 → PHP（你用的版本）→ **设置** → **重载配置**（或「服务」→ 重启）
- **等 5 分钟**：不重启也行，但期间仍是旧配置

**第 6 步：验证是否生效**

在网站根目录临时建一个 `phpinfo-check.php`：

```php
<?php echo ini_get('open_basedir');
```

浏览器访问 `https://你的域名/phpinfo-check.php`，输出里应能看到 `/www/wwwroot/consult-data/`。

**验证完立刻删掉这个文件**——它会暴露服务器路径信息。

更直接的验证：回站点提交一次表单，不再报 `open_basedir` 就是成功了。

### 方式三：不用改 open_basedir

把 `api/config.php` 里的 `data_dir` 改成站点**内部**目录：

```php
'data_dir' => __DIR__ . '/data',
```

但**必须**在 Nginx 加一条规则挡住，否则 CSV 里的客户手机号会被任何人下载：

宝塔 → 网站 → 设置 → **配置文件**，在 `server { }` 内加入：

```nginx
location ^~ /api/data/ { deny all; }
```

保存后 Nginx 自动 reload。然后访问 `https://你的域名/api/data/` 应返回 403。

> 三种方式选一种即可，**不要同时用**。方式二最平衡：保留防跨站防护，只放开一个数据目录。

---

## 6. 配置 HTTPS

1. 宝塔 → 网站 → 设置 → **SSL**
2. 选 **Let's Encrypt** → 勾选域名 → 申请（免费，自动续期）
3. 申请成功后打开「**强制 HTTPS**」

> 表单是 `fetch` 提交的，站点必须 HTTPS，否则混合内容会被浏览器拦截。

---

## 7. 确认 Nginx 配置

宝塔建站时自动生成的配置**基本不用改**，只需确认两点：

- **默认文档**包含 `index.html`（宝塔默认就有）
- **不要**给静态站开「伪静态」（本项目不用，开了反而可能 404）

如果之前在别处配过 `location ~ \.php$` 的拦截规则，确保 `/api/consult.php` 能正常执行。

改完配置点「保存」→ 宝塔自动 reload。

## 8. 上线后必做的 4 项检查

### ① 页面能打开
浏览器访问 `https://你的域名/` → 首页正常显示。

### ② PHP 在跑
访问 `https://你的域名/api/consult.php`

应看到：
```json
{"ok":false,"error":"method_not_allowed"}
```
这是 GET 的**预期返回**，不是报错。如果看到 404 → PHP 没配好；看到 502 → PHP-FPM 没启动。

### ③ 敏感文件不可下载
逐个访问，**全部应该是 404 或空**：

| 路径 | 期望 |
| --- | --- |
| `/api/config.php` | 空内容（PHP 执行后无输出，不是源码） |
| `/api/leads.php` | 404 |
| `/api/data/` | 403 |
| `/dist.zip` | 404 ← **务必删掉上传的 zip** |

> 如果 `config.php` 返回的是 PHP 源码（能看到 `wecom_webhook` 字样），说明 PHP 没在跑，**立刻关站修复**——里面是你的群机器人密钥。

### ④ 真实提交一次
用 [consult-smoke-test.js](../_build/consult-smoke-test.js) 在 F12 控制台跑一遍（会真的写 CSV + 发群消息），或者手动填表提交。

预期：
- 页面出现「提交成功」
- 企微群收到「**【官网合作咨询】**」消息
- `/www/wwwroot/consult-data/consultations.csv` 新增一行，「通知状态」列 = `已发送`

## 9. 日常更新

改了内容后：

```bash
cd site
npm run check && npm run build
```

然后把新的 `dist/` 覆盖上去。**只覆盖 `index.html`、`catalog.html`、`assets/` 即可**，不要动服务器上的 `api/config.php` 和 `consult-data/`。

## 10. 常见问题速查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 打开是宝塔默认页 | 默认 `index.html` 没删 | 删掉根目录的默认 index.html |
| 页面样式全丢 | `assets/` 没传或路径不对 | 确认 `assets/` 在根目录下 |
| 表单提交 503 | `config.php` 不存在 | 按第 3 步创建 |
| 表单提交 500 + 存储不可用 | `consult-data` 无写权限 | 权限 755/775，属主 www |
| `open_basedir restriction` | 数据目录在允许范围外 | 按第 5 步放开 |
| 提交成功但群里没消息 | Webhook 错或被移除 | 看 `consult-data/webhook-error.log` |
| 429 提交太频繁 | 同 IP 限流 | 等 10 分钟；或调 `rate_limit` |
| CSV 用 Excel 打开乱码 | 编码问题 | 已带 UTF-8 BOM；仍乱码用「数据→从文本/CSV」导入选 UTF-8 |
| `/dist.zip` 能下载 | 上传的压缩包没删 | **立刻删除**，会泄露接口文件结构 |
