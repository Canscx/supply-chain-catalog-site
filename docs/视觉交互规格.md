# 企业供应链展示站 · 视觉交互规格

**版本**：v1.2 · 2026-11-19

## 1. 设计概念

**一条线穿过整页，内容挂在线上。**

不是装饰性的竖线，是结构：品类索引的每个单元左侧有一个节点圆点，悬停时节点放大、线段变绿；业务范围网格用 1px 分隔线而不是卡片；结果区用横线分隔分组。整套视觉回答的是「这些东西是同一条链上的节点」。

拒绝的做法：卡片网格、大圆角、阴影分层、玻璃拟态、「数字 + 标签」的指标展示。

## 2. 配色：铜与铜绿

**策略**：Committed 偏 Restrained。中性色承担约 90% 面积，铜绿只出现在主操作、当前选中态、链接、图标承载层；黄铜只用于品类区分标记。

选这个方向的理由：目录里就有电解铜、铝锭、锌锭、铜杆，铜的氧化本身就是天然的双色系统。同时避开两个用滥的方向：海军蓝配金、青绿科技风。

全部用 OKLCH 定义，浅深两套独立调整，深色不是反色。

### 对比度实测（WCAG）

| 组合 | 浅色 | 深色 |
| --- | --- | --- |
| 正文 / 页面 | 15.9:1 | 16.2:1 |
| 次级文字 / 页面 | 7.1:1 | 8.7:1 |
| 元信息 / 页面 | 4.7:1 | 6.2:1 |
| 强调色 / 页面 | 5.7:1 | 10.3:1 |

正文门槛 4.5:1，全部满足。分隔线（1.3:1）与输入框边框（2.9:1 / 2.7:1）是有意低于 3:1 的非文本装饰，输入框另有 1px 实线边框与背景色差保证可辨认。

## 3. 排版

中文字面优先。字体栈：PingFang SC → HarmonyOS Sans SC → Source Han Sans SC → Noto Sans CJK SC → Microsoft YaHei，逐级降级，不加载网络字体（省一次往返，中文网络字体动辄数 MB）。

| 层级 | 字号 | 用途 |
| --- | --- | --- |
| display | `clamp(1.85rem, 1.15rem + 3.1vw, 3.15rem)` | 首屏主张、页面标题 |
| h2 | `clamp(1.25rem, 1.05rem + 0.85vw, 1.65rem)` | 区块标题 |
| lead | `clamp(0.9375rem, 0.9rem + 0.28vw, 1.0625rem)` | 导语 |
| body | 1rem / 1.7 | 正文 |
| meta | 0.8125rem | 元信息 |

相邻层级比例 ≥ 1.25。标题字距 -0.022em（不为「设计感」压到 -0.05em，那样字会挤在一起）。数字用等宽字型 `font-variant-numeric: tabular-nums`，所以「19 条」「144 条」在各行都能对齐。

首屏两行共用 display 字号基准：第一行 +2px、第二行 -3px，行高 1.32，形成轻微的主次层级和更松的竖向呼吸。

首页五个区块标题（业务范围、准入门槛、合作流程、关于我们、联系我们）统一居中，字号为 19px（17px + 2px）；原有右侧辅助说明改为标题下方居中的 12px 小字。

正文行长上限 65ch，导语 34em。

## 4. 布局

- 内容最大宽 1200px，页边距 56px（桌面）/ 32px（平板）/ 20px（手机）
- 分组列表：手机 1 列、720px+ 2 列、900px+ 3 列、1100px+ 4 列
- 业务范围：手机 2 列、平板 4 列、桌面 6 列；前五个品类固定为机器人、无人机、科技链条、可变品、可定制，作为主推露出
- 所有间距用 `clamp()` 随视口流动，不写死断点
- 准入门槛：三组上下排列，材料清单 720px 以上两栏、手机单栏
- 合作流程：1000px 以上蛇形两行（01→04 左到右，04 右侧下折接 05，05→08 右到左），以下纵向单列；连线只用横线、竖线与圆角折线，不画箭头
- 关于我们：标题居中，正文最大宽度 68ch 居中、段落左对齐，强调句用主题强调色，下辖公司清单用细横线与正文分隔
- 联系我们：最大宽度 780px 单列，每条公司/地址用两列标签值排版和 1px 分隔线；手机保持单列，长地址允许换行
- 我要合作：桌面右下角固定悬浮胶囊，距边 16–32px、底部 20px；手机改为底部固定条，左右 16px，底部适配 safe-area，页面底部留 74px 防遮挡

## 5. 交互细节

### 5.1 吸附导航

半透明页面色 + `backdrop-filter: blur(14px) saturate(1.4)`。滚动超过 4px 时才出现底边框，避免初始状态多一条线。

不支持 `backdrop-filter` 时（`@supports not`）回退为实色。滚动时高度不变，锚点跳转用 `scroll-margin-block-start` 留出空间。

### 5.2 搜索栏吸附

只吸附搜索栏，不吸附业务范围块。所以滚动时业务范围块会滚走，搜索框固定。

吸附层高约 74px，结果行的 `scroll-margin-block-start` 设为 `nav高度 + 86px`，保证滚过去不被遮住。

### 5.3 聚焦与键盘

- 所有可点元素 ≥ 44×44px（移动端）/ ≥ 24px（桌面）
- `:focus-visible` 用 2px 强调色描边 + 3px 偏移
- 分组折叠用 button 而非 div，带 `aria-expanded`
- 品类单元是 button 而非链接（它触发筛选，不是导航）
- 结果行 `tabindex="-1"`，点击品类后焦点移过去，屏幕阅读器能读到新计数

### 5.4 动效

主动效只做四处，另有联系方式复制后的轻提示：

1. 首屏编排式入场：元信息 → 主张 → 导语依次上浮 9px，间隔 70ms，缓动 `cubic-bezier(0.16, 1, 0.3, 1)`
2. 品类单元与分组依次浮现，间隔 22ms
3. 合作流程光点：主题色光点沿 01→08 循环流动，桌面 9s 一圈、手机按步骤每 0.8s 前进一段；到 08 后淡出重启
4. 主推标记圆点：前五个品类标签上的 4px 主题色圆点做 2.8s 轻微呼吸，幅度克制

`prefers-reduced-motion: reduce` 时全部降为 0.01ms，合作流程光点直接隐藏、静态连线保留，主推圆点保持静止。滚动行为同步降为 `auto`。

### 5.5 复制联系方式

公司名称与地址是独立按钮，点击后写入剪贴板；成功后按钮图标由复制变为勾选，1.6 秒后恢复，底部居中提示「公司名称已复制」或「地址已复制」1.8 秒。按钮带明确的 `aria-label`，提示区域使用 `role="status"` + `aria-live="polite"`。剪贴板 API 不可用时回退到临时 textarea + `execCommand("copy")`。移动端按钮触控高度不小于 44px。

### 5.6 我要合作弹窗

入口本身是链接，默认跳到首页 `#contact`；JS 可用时拦截为原生 dialog。打开后给 body 加 `consult-open` 锁滚动，焦点落到公司名字；关闭（右上角、遮罩、ESC、成功后的关闭按钮）恢复焦点到入口。

表单字段：公司名字、供应链品类、单月需求、目前发票额度、联系人、联系电话、同意勾选。前端先校验，错误显示在字段下方并用 `aria-invalid` / `aria-describedby` 关联；提交中按钮禁用并显示「提交中…」；15 秒超时；成功后显示成功面板，不重复发送。

品类显示首页业务范围前 5 个主推大类，第 6 个为「我要定制」；前 5 个可多选并同步到输入框，也可以直接手写；「我要定制」展开 300 字文本框，与已选大类可同时存在。

弹窗桌面最大宽 560px、最大高 94vh；手机为底部抽屉，最高 92dvh，内部滚动。所有间距、颜色、圆角沿用 tokens，1px 边框，无重阴影。

## 7. 移动端适配原则

不是把桌面缩小。具体差异：

1. **导航**：桌面显示「首页 / 四类资质 / 资产配置」，手机保留品牌 + 「四类资质」「资产配置」两个外链按钮 + 主题开关（隐藏「首页」文字链接，点品牌回首页）
2. **业务范围**：手机折叠到 8 个，其余走展开按钮
3. **品类筛选**：桌面用左侧栏（吸顶），手机用原生 select（符合系统习惯、可语音输入）
4. **分列**：链条列表桌面 4 列，手机 1 列
5. **触控**：移动端所有可点区域 ≥ 44px
6. **合作流程**：1000px 以下从两行蛇形改为纵向单列，节点与连接线保持左对齐，连接段加长到 36px
7. **联系我们**：始终单列；320px 下标签列缩到 4.2em，长地址自动换行
8. **我要合作**：手机不做悬浮球，改底部固定操作条；弹窗改底部抽屉，内部滚动，提交按钮随表单滚动到可见位置

## 8. 文案原则

- 用具体名词和动词，不用「赋能」「一站式」「领先」
- 数字必须能对上（144 条就是 144 条）
- 不写没把握的承诺（不写「保证时效」「最低价」）
- 按钮说清会发生什么（「查看全部链条」「换品类」「清空筛选」）
- 不用破折号连接句子
