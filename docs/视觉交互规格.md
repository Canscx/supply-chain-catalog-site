# 企业供应链展示站 · 视觉交互规格

**版本**：v1.9 · 2026-11-23

## 1. 设计概念

**一条线穿过整页，内容挂在线上。**

不是装饰性的竖线，是结构：品类索引的每个单元左侧有一个节点圆点，悬停时节点放大、线段变绿；增量品类明细表用 1px 分隔线而不是卡片；目录页结果区用横线分隔分组。整套视觉回答的是「这些东西是同一条链上的节点」。

背景层沿用同一套铜绿与黄铜：全站固定一层顶部聚焦的极淡网格和约 4% 的轻微噪点。它只负责氛围，始终位于内容层之下，不拦截点击。

拒绝的做法：卡片网格、大圆角、阴影分层、玻璃拟态、「数字 + 标签」的指标展示。

## 2. 配色：铜与铜绿

**策略**：Committed 偏 Restrained。中性色承担约 90% 面积，铜绿只出现在主操作、当前选中态、链接、图标承载层；黄铜只用于品类区分标记。

选这个方向的理由：目录里就有电解铜、铝锭、锌锭、铜杆，铜的氧化本身就是天然的双色系统。同时避开两个用滥的方向：海军蓝配金、青绿科技风。

全部用 OKLCH 定义，浅深两套独立调整，深色不是反色。

## 3. 排版

中文字面优先。字体栈：PingFang SC → HarmonyOS Sans SC → Source Han Sans SC → Noto Sans CJK SC → Microsoft YaHei，逐级降级，不加载网络字体（省一次往返，中文网络字体动辄数 MB）。

| 层级 | 字号 | 用途 |
| --- | --- | --- |
| display | `clamp(1.85rem, 1.15rem + 3.1vw, 3.15rem)` | 首屏主张、页面标题 |
| h2 | `clamp(1.25rem, 1.05rem + 0.85vw, 1.65rem)` | 区块标题 |
| lead | `clamp(0.9375rem, 0.9rem + 0.28vw, 1.0625rem)` | 导语 |
| body | 1rem / 1.7 | 正文 |
| meta | 0.8125rem | 元信息 |

相邻层级比例 ≥ 1.25。标题字距 -0.022em（不为「设计感」压到 -0.05em，那样字会挤在一起）。数字用等宽字型 `font-variant-numeric: tabular-nums`，所以「19 条」「146 条」在各行都能对齐。

首屏两行共用 display 字号基准：第一行 +2px、第二行 -3px，行高 1.32，形成轻微的主次层级和更松的竖向呼吸。

首页五个区块标题（增量品类明细、准入门槛、合作流程、关于我们、联系我们）统一居中，字号为 19px（17px + 2px）；原有右侧辅助说明改为标题下方居中的 12px 小字。

正文行长上限 65ch，导语 34em。

## 4. 布局

- 内容最大宽 1200px，页边距 56px（桌面）/ 32px（平板）/ 20px（手机）
- 右侧章节尺规：仅首页桌面端显示，只列总览、增量品类明细、准入门槛、合作流程、关于我们、联系我们六个主刻度
- 全站背景：fixed 装饰层，含 64px（手机 44px）顶部聚焦轻网格与轻微噪点；不进入内容层、不拦截点击
- 分组列表：手机 1 列、720px+ 2 列、900px+ 3 列、1100px+ 4 列
- 增量品类明细：手机 1 列、平板 2 列、桌面 3 列；每格完整显示该品类全部小类名称，不用省略号；不折叠、不横向滚动，手机纵向滑动看完 18 个品类
- 首屏自评入口：标题下两枚主色浅化 30% 的胶囊按钮，白字，带内高光与淡荧光；桌面并排，560px 以下单列全宽
- 首屏铺满：最小高 `calc(100svh - var(--nav-h))`（无 svh 时退回 `100vh`），内容纵向居中，底部内边距 76–108px；手机再抬高 74px 避开底部「我要合作」条，使「增量品类明细」整段落在折叠线以下
- 下滑提示：首屏底部居中的强调色胶囊，高 44px、圆角 999px、1px 强调色描边 + 强调色浅底 + 深强调色粗体字（14px）；右侧 20px 下箭头，2.4px 描边 + 强调色 drop-shadow 荧光；箭头 1.6s 上下轻浮（±3px）；悬停翻为实心强调色 + 反白文字；滚到品类段进入视口 80% 后淡出并禁用点击
- 所有间距用 `clamp()` 随视口流动，不写死断点
- 准入门槛：单组（全部链条）上下排列，材料清单 720px 以上两栏、手机单栏
- 合作流程：1000px 以上蛇形两行（01→04 左到右，04 右侧下折接 05，05→08 右到左），以下纵向单列并整条按内容宽度居中；连线只用横线、竖线与圆角折线，不画箭头
- 关于我们：标题居中，正文最大宽度 68ch 居中、段落左对齐，强调句用主题强调色，下辖公司清单用细横线与正文分隔
- 联系我们：最大宽度 780px 单列，每条公司/地址用两列标签值排版和 1px 分隔线；手机保持单列，长地址允许换行
- 我要合作：桌面右下角固定悬浮胶囊，距边 16–32px、底部 20px；手机改为底部固定条，左右 16px，底部适配 safe-area，页面底部留 74px 防遮挡

## 5. 交互细节

### 5.1 吸附导航

半透明页面色 + `backdrop-filter: blur(14px) saturate(1.4)`。滚动超过 4px 时才出现底边框，避免初始状态多一条线。

不支持 `backdrop-filter` 时（`@supports not`）回退为实色。滚动时高度不变，锚点跳转用 `scroll-margin-block-start` 留出空间。

### 5.2 搜索栏吸附

只吸附搜索栏，不吸附增量品类明细表。所以滚动时表格会滚走，搜索框固定。

搜索框默认隐藏；启用后只过滤品类表格，不再有独立结果行或滚动锚点。

### 5.3 聚焦与键盘

- 所有可点元素 ≥ 44×44px（移动端）/ ≥ 24px（桌面）
- `:focus-visible` 用 2px 强调色描边 + 3px 偏移
- 目录页分组折叠用 button 而非 div，带 `aria-expanded`
- 首页品类单元是指向目录页对应品类的链接，整格可点
- 首页不保留结果行与筛选计数；品类格内的小类文字直接可读

### 5.4 动效

主动效共七项，另有联系方式复制后的轻提示：

1. 首屏编排式入场：元信息 → 主张 → 导语依次上浮 9px，间隔 70ms，缓动 `cubic-bezier(0.16, 1, 0.3, 1)`
2. 增量品类明细表进入视口时整体上浮 18px 淡入
3. 合作流程光点：主题色光点沿 01→08 循环流动，桌面 9s 一圈、手机按步骤每 0.8s 前进一段；到 08 后淡出重启
4. 自评入口荧光：静态内高光 + 淡光晕，悬停时光晕扩散；不做持续闪烁
5. 背景层：网格只保留在页面上部并向下自然淡出，噪点层保持静止；打印时隐藏
6. 滚动显现：带 `data-reveal` 的区块进入视口后从下方 18px 淡入，700ms `ease-out-expo`；流程步骤、门槛分组、联系记录按 50-80ms 级联延迟。只播放一次，`prefers-reduced-motion: reduce` 时直接显示
7. 首屏下滑提示：底部胶囊内的箭头 1.6s 上下轻浮（位移 ±3px、透明度 0.78→1），箭头带强调色荧光；滚到增量品类明细后整条提示淡出并上移 8px；`prefers-reduced-motion: reduce` 时箭头静止、提示仍常驻可点

`prefers-reduced-motion: reduce` 时全部降为 0.01ms，合作流程光点直接隐藏、静态连线保留。滚动行为同步降为 `auto`。

### 5.5 复制联系方式

公司名称与地址是独立按钮，点击后写入剪贴板；成功后按钮图标由复制变为勾选，1.6 秒后恢复，底部居中提示「公司名称已复制」或「地址已复制」1.8 秒。按钮带明确的 `aria-label`，提示区域使用 `role="status"` + `aria-live="polite"`。剪贴板 API 不可用时回退到临时 textarea + `execCommand("copy")`。移动端按钮触控高度不小于 44px。

### 5.6 我要合作弹窗

入口本身是链接，默认跳到首页 `#contact`；JS 可用时拦截为原生 dialog。打开后给 body 加 `consult-open` 锁滚动，焦点落到公司名字。关闭只由右上角关闭按钮（以及成功面板的「关闭」按钮）触发；点击遮罩、按 ESC 都不会关闭，避免误触丢失填写内容。关闭后恢复焦点到入口。

右上角关闭按钮为 44×44 圆形，铜绿实底、反色叉号并带一圈 `accent-soft` 光环；悬停底色加深并旋转 90°，聚焦时有 3px 可见轮廓。

表单字段：公司名字、供应链品类、单月需求、目前发票额度、联系人、联系电话、同意勾选。前端先校验，错误显示在字段下方并用 `aria-invalid` / `aria-describedby` 关联；提交中按钮禁用并显示「提交中…」；15 秒超时；成功后显示成功面板，不重复发送。未提交的填写内容自动保存为本机浏览器草稿（7 天有效），关闭或刷新后再次打开会恢复公司、品类、定制描述、需求、发票额度、联系人和电话；同意勾选不保存、需重新确认；提交成功后清除草稿。

品类显示首页增量品类明细前 5 个品类（科技链条、智能装备、新能源、电子产品、农副产品），第 6 个为「我要定制」；前 5 个可多选并同步到输入框，也可以直接手写；「我要定制」展开 300 字文本框，与已选大类可同时存在。

弹窗桌面最大宽 560px、最大高 94vh；手机为底部抽屉，最高 92dvh，内部滚动。所有间距、颜色、圆角沿用 tokens，1px 边框，无重阴影。

## 7. 移动端适配原则

不是把桌面缩小。具体差异：

1. **导航**：桌面显示「首页 / 资质申报 / 资产配置」，手机保留品牌 + 「资质申报」「资产配置」两个外链按钮 + 主题开关（隐藏「首页」文字链接，点品牌回首页）
2. **增量品类明细**：每个品类名前带 emoji；手机 1 列纵向排列，不折叠
3. **品类筛选**：桌面用左侧栏（吸顶），手机用原生 select（符合系统习惯、可语音输入）
4. **分列**：链条列表桌面 4 列，手机 1 列
5. **触控**：移动端所有可点区域 ≥ 44px
6. **合作流程**：1000px 以下从两行蛇形改为纵向单列，整条流程按内容宽度在页面中居中，节点与连接线保持左对齐，连接段加长到 36px
7. **联系我们**：始终单列；320px 下标签列缩到 4.2em，长地址自动换行
8. **我要合作**：手机不做悬浮球，改底部固定操作条；弹窗改底部抽屉，内部滚动，提交按钮随表单滚动到可见位置
9. **自评入口**：560px 以下由并排改为单列全宽，保持 48px 触控高度

## 8. 文案原则

- 用具体名词和动词，不用「赋能」「一站式」「领先」
- 数字必须能对上（146 条就是 146 条）
- 不写没把握的承诺（不写「保证时效」「最低价」）
- 按钮说清会发生什么（「查看全部链条」「换品类」「清空筛选」）
- 不用破折号连接句子
