# 咨询表单部署说明（宝塔 PHP 项目）

本文只讲「我要合作」咨询表单上线需要做的事。页面本身仍是静态 HTML，不需要 Node、不需要数据库、不需要改现有页面结构。

## 1. 先准备企业微信群机器人

1. 打开三人微信群 → 群设置 → 群机器人 → 添加机器人。
2. 选择「自定义消息推送」，名称可填「链条咨询推送」，简介填「客户咨询推送」。
3. 创建后复制 Webhook 地址，格式为：
   https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=...
4. 先把地址保存到本机的 `企微bot-webhook.txt`，不要发到公开聊天、不要提交 git。

> 说明：智能机器人的 Bot ID / Secret 不能直接给网页 POST 使用。智能机器人主动推送需要 WebSocket 长连接和 Node 常驻进程；这里用的是官方「群机器人 Webhook」，一次 HTTPS POST 即可。

## 2. 上传站点

1. 在项目根目录执行：
   ```bash
   cd site
   npm run check
   npm run build
   ```
2. 打开宝塔 → 文件 → 网站根目录（通常是 `/www/wwwroot/你的域名`）。
3. 把 `site/dist/` 里的全部文件上传到网站根目录，覆盖旧文件。
4. 确认网站根目录下出现：
   - `index.html`
   - `catalog.html`
   - `assets/`
   - `api/consult.php`
   - `api/leads.php`
   - `api/config.example.php`
   - `api/cacert.pem`

## 3. 创建 api/config.php

1. 进入网站根目录的 `api` 文件夹。
2. 复制 `config.example.php`，改名为 `config.php`。
3. 编辑 `config.php`，填两项：
   - `wecom_webhook`：第 1 步复制的群机器人 Webhook；
   - `admin_token`：一串随机口令，用于下载 CSV，建议 32 位以上，不要用生日、手机号。
4. `data_dir` 保持默认即可，默认是网站根目录之外的 `/www/wwwroot/consult-data`。

> `config.php` 只放在服务器上，不要提交 git。代码仓库里只有空的 `config.example.php`。

## 4. 创建 CSV 数据目录

默认路径：`/www/wwwroot/consult-data`

1. 宝塔 → 文件 → 进入 `/www/wwwroot`。
2. 新建文件夹 `consult-data`。
3. 权限设为 `755`，属主设为 `www`（如果面板有「设置所有者」选项）。
4. 确认 PHP 能写入；如果提交时报「存储不可用」，把权限临时改成 `775` 再试，或让宝塔运维协助。

提交成功后，CSV 路径为：

`/www/wwwroot/consult-data/consultations.csv`

该目录在网站根目录之外，不能通过 URL 直接访问。若你把 `data_dir` 改到了网站根目录内，请务必在 Nginx 站点配置加：

```nginx
location ^~ /api/data/ { deny all; }
```

## 5. 检查 PHP 环境

1. 宝塔 → 网站 → 设置 → PHP 版本：选择 PHP 7.4 或更高（推荐 8.0+）。
2. 确认 PHP 已启用 `curl` 和 `openssl`（大多数宝塔环境默认启用）。
3. 浏览器访问：
   `https://你的域名/api/consult.php`
   看到类似下面的 JSON 就说明 PHP 正常：
   ```json
   {"ok":false,"error":"method_not_allowed"}
   ```
   这是 GET 请求的预期返回，不是错误。

## 6. 测试提交

可以用浏览器打开首页，点右下角「我要合作」填写测试数据；也可以命令行：

```bash
curl -X POST 'https://你的域名/api/consult.php' \
  -H 'Content-Type: application/json' \
  -d '{
    "company": "测试公司（请忽略）",
    "contact": "测试",
    "phone": "13800138000",
    "categories": "科技链条",
    "custom_chain": "",
    "custom_requested": false,
    "demand": "50",
    "invoice": "每月可开10万元专票",
    "agree": true,
    "source": "index.html",
    "request_id": "deploy-test-1",
    "website": ""
  }'
```

预期返回：

```json
{"ok":true,"id":"...","notified":true}
```

同时检查：

1. 群里收到「【官网合作咨询】…」消息；
2. `/www/wwwroot/consult-data/consultations.csv` 新增一行；
3. 打开 `https://你的域名/api/leads.php?token=你的口令` 能下载 CSV。

## 7. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 405 JSON | 直接用浏览器打开接口 | 正常，接口只接受 POST |
| 503 | `api/config.php` 不存在或格式不对 | 从 `config.example.php` 重新复制并填值 |
| 500 / 存储不可用 | `consult-data` 不存在或 PHP 无写权限 | 创建目录，权限 755/775，属主 www |
| 提交成功但群里没消息 | Webhook 错误或群机器人被移除 | 查看 `consult-data/webhook-error.log`，重新复制 Webhook |
| 429 | 同一 IP 提交太频繁 | 等待 10 分钟；必要时调整 `config.php` 的 `rate_limit` |
| CSV 打不开或乱码 | 用 Excel 直接打开 | CSV 已带 UTF-8 BOM，若仍乱码用「数据 → 从文本/CSV」导入并选 UTF-8 |

## 8. 安全注意事项

- 不要把 `企微bot-webhook.txt`、`api/config.php`、`consult-data/` 提交到 git 或 GitHub。
- 不要把 Webhook 地址写进前端 JS、README、PRD、截图或公开文档。
- `api/leads.php` 的 `admin_token` 等同于 CSV 下载密码，泄露后请立即更换。
- CSV 含客户手机号等个人信息，只用于业务对接，不要公开分享。
- 定期备份 `/www/wwwroot/consult-data/consultations.csv`。

## 9. 上线后建议

1. 用手机和电脑各提交一次真实测试，确认弹窗、CSV、群消息都正常。
2. 让群机器人只留在需要接收通知的群里，避免无关人员看到客户信息。
3. 如果咨询量变大，再考虑把 CSV 升级为 SQLite/MySQL 和后台管理；当前阶段不需要。
