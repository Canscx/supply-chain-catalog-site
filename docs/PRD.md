# 企业供应链展示站 · 产品需求文档

**版本**：v1.0 · 2026-11-18
**状态**：首版已实现，待内容与品牌确认后发布
**实现**：`site/`（Astro 静态站），产物 `site/dist/`

## 1. 要解决的问题

来访的企业客户通常带着一个具体品类来（玉米、锂电池、集成电路），但不知道我们到底能接什么、接到什么程度。

这个站要回答两个问题：

1. 这家公司覆盖哪些业务方向？
2. 我要的那个品类，有没有链条可以谈？

它不承担转化，不收集信息，不做交易。验收标准是「看懂了」，不是「留了电话」。

## 2. 核心设计判断

**单品是点，链条是线。** 示例数据里每一条都是「玉米·链条」而不是「玉米」，这个命名法构成了页面结构的基础：展示的不是孤立的产品名，而是产品背后的完整链路。

所以首页第一句话是「按链条供货，不按单品」。这句话定调，后面所有内容都在解释它。

**不做的事**：不编造案例、不写未经核实的指标、不做品牌背书、不放轮播、不做产品详情页、不出现金额与门槛。目录之外的任何承诺都不写。

## 3. 页面与结构

全站两页：首页（`/`）与产品链条目录（`/catalog.html`）。两页可独立直达、刷新不丢状态。

### 3.1 首页

从上到下：

| 区块 | 内容 | 行为 |
| --- | --- | --- |
| 首屏 | 覆盖品类数与链条数、主张句、一段说明 | 无操作，只有信息 |
| 吸附搜索栏 | 搜索产品名称 | 滚动时吸附在导航下方，不遮挡内容 |
| 业务范围 | 16 个品类 + 「全部品类」，每格含品类名、链条数、2 条代表链条 | 点品类即筛选，页面滚到结果区，该块收成一行 |
| 结果计数 | 「共 N 条链条」+ 清空筛选 | 作为滚动锚点 |
| 分组列表 | 16 个品类分组，组内是链条名 | 点组标题可展开/收起；搜索或选中品类时自动展开 |

**业务范围的响应式**（这是首页最关键的一块，经历了三轮调整）：

| 宽度 | 列数 | 行数 | 折叠 |
| --- | --- | --- | --- |
| < 720px 手机 | 2 列 | 默认 4 行（8 个品类）| 其余走「展开全部 16 个品类」 |
| 720–999px 平板 | 4 列 | 5 行 | 不折叠，「全部品类」独占末行 |
| ≥ 1000px 桌面 | 6 列 | 3 行（6+6+4） | 不折叠，「全部品类」占满末行剩余 2 列 |

手机上折叠到 8 个，是因为 16 个品类会占掉整整一屏，把搜索结果挤出首屏。

**点击品类之后**：

1. 列表只剩该品类
2. 业务范围块收成一行「农副产品 · 19 条 · 换品类」
3. 页面滚到「共 19 条链条」，且不被吸附层遮挡
4. 点「换品类」块展开回网格，筛选不变，焦点回到刚才那个品类

### 3.2 目录页

| 区块 | 内容 |
| --- | --- |
| 标题区 | 「← 返回首页」（固定链接，不依赖浏览器历史）、标题、搜索框 |
| 品类筛选 | 桌面左侧栏，手机原生 select |
| 结果区 | 分组折叠列表，默认全折叠 |

## 4. 检索规则

命中范围是**链条名 + 别名**。别名是同一实体的其他中文叫法，只参与匹配不显示。

这条规则解决的是真实问题：客户嘴里说的是「螺纹钢」，我们目录里写的是「钢材（含螺纹钢）」；客户说「塑料粒子」，我们写「PE聚乙烯（塑料）」；客户说「中草药」，我们写「中药材」。

匹配前统一归一化：去掉空白、`.` `·` `•` `-` `/` `、` `,` 这类分隔符，英文字母转小写。所以：

- 「玉米」「玉米.链条」「玉米·链条」都只命中同一条
- 「螺纹钢」命中「钢材（含螺纹钢）·链条」
- 「塑料粒子」「低密度聚乙烯」都命中「PE聚乙烯（塑料）·链条」

品类与关键词取**交集**：选了新能源再搜「玉米」，结果是 0 条并显示空态，不会串到农副产品。

中文输入法组合期不触发过滤，确认后才更新。

## 5. 主题

- 首次访问固定浅色，**不读**系统深色偏好
- 手动切换后写入 localStorage，跨页与刷新保持
- 存储在 `<head>` 内联脚本里同步读取并设置，避免首帧闪白
- 存储不可用或值非法 → 回退浅色，当页仍可切换
- 开关是原生 button，带 `aria-pressed` 与可读名称，键盘可达

## 6. URL 约定

| 参数 | 含义 | 缺省/非法时 |
| --- | --- | --- |
| `category` | 品类 id，如 `agri` | 视为全部分类 |
| `q` | 关键词，URL 编码 | 视为空 |

逐字输入用 `replaceState`，不堆历史。全清后移除空参数。折叠状态与主题不写进 URL。

## 7. 不做的事

后端、账户、表单收集、交易、咨询提交、产品详情页、轮播、任何虚构案例/数字/背书、AI 算力与定制软件开发（特殊渠道，本期不纳入）。
