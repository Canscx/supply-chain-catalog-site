# 企业供应链展示站 · 产品需求文档

**版本**：v1.2 · 2026-11-19
**状态**：首版已实现，待内容与品牌确认后发布
**实现**：`site/`（Astro 静态站 + 单文件 PHP 咨询接口），产物 `site/dist/`

## 1. 要解决的问题

来访的企业客户通常带着一个具体品类来（玉米、锂电池、集成电路），但不知道我们到底能接什么、接到什么程度。

这个站要回答两个问题：

1. 这家公司覆盖哪些业务方向？
2. 我要的那个品类，有没有链条可以谈？

它主要承担展示与初步留资：客户可以先看懂，再通过「我要合作」提交需求。验收标准是「看懂了」和「愿意留下需求」。

## 2. 核心设计判断

**单品是点，链条是线。** 页面按链条组织内容，但链条名直接用产品名（玉米、PCB电路板），不再拼接「·链条」后缀；展示的不是孤立的产品名，而是产品背后的完整链路。

所以首页第一句话是「按链条供货，不按单品」。这句话定调，后面所有内容都在解释它。

**不做的事**：不编造案例、不写未经核实的指标、不做品牌背书、不放轮播、不做产品详情页、不出现报价与交易金额。目录之外的任何承诺都不写；准入门槛按业务提供的材料清单如实展示。

## 3. 页面与结构

全站两页：首页（`/`）与产品链条目录（`/catalog.html`）。两页可独立直达、刷新不丢状态。

### 3.1 首页

从上到下：

| 区块 | 内容 | 行为 |
| --- | --- | --- |
| 首屏 | 覆盖品类数与链条数、主张句、一段说明 | 无操作，只有信息 |
| 吸附搜索栏 | 搜索产品名称 | 滚动时吸附在导航下方，不遮挡内容 |
| 业务范围 | 20 个品类 + 「全部品类」，前五个为机器人、无人机、科技链条、可变品、可定制；每格含品类名、链条数、2 条代表链条 | 点品类即筛选，页面滚到结果区，该块收成一行 |
| 结果计数 | 「共 N 条链条」+ 清空筛选 | 作为滚动锚点 |
| 分组列表 | 20 个品类分组，组内是链条名 | 点组标题可展开/收起；搜索或选中品类时自动展开 |
| 准入门槛 | 研发服务/信息服务、机器人/无人机、其他三类链条的材料清单与对盾要求 | 纯信息展示，无操作 |
| 合作流程 | 确定合作 → 支付1000意向金 → 建立工作群 → 资料审核 → 报量 → 支付服务费 → 上下游开票 → 走流水 | 桌面蛇形横向、窄屏纵向的无箭头纯信息流程图，主题色光点循环指向 |
| 关于我们 | 集团定位、「让数据产生价值」理念、下辖公司 | 纯信息展示，无操作 |
| 联系我们 | 4 家公司名称与地址，统一用「公司：」「地址：」标签 | 公司名称、地址均可点击复制到剪贴板，并给出成功提示 |
| 我要合作 | 全站常驻入口：桌面右下角悬浮胶囊，手机底部固定条 | 点击打开咨询弹窗，提交公司、联系人、电话、品类、需求与发票额度 |

**业务范围的响应式**（这是首页最关键的一块，经历了三轮调整）：

| 宽度 | 列数 | 行数 | 折叠 |
| --- | --- | --- | --- |
| < 720px 手机 | 2 列 | 默认 4 行（8 个品类）| 其余走「展开全部 20 个品类」 |
| 720–999px 平板 | 4 列 | 品类 5 行 | 不折叠，「全部品类」独占末行 |
| ≥ 1000px 桌面 | 6 列 | 4 行（6+6+6+2） | 不折叠，「全部品类」补满末行 |

手机上折叠到 8 个，是因为 20 个品类会占掉整整一屏，把搜索结果挤出首屏。

**点击品类之后**：

1. 列表只剩该品类
2. 业务范围块收成一行「农副产品 · 19 条 · 换品类」
3. 页面滚到「共 19 条链条」，且不被吸附层遮挡
4. 点「换品类」块展开回网格，筛选不变，焦点回到刚才那个品类

### 3.2 目录页

| 区块 | 内容 |
| --- | --- |
| 标题区 | 「← 返回首页」（固定链接，不依赖浏览器历史）、标题、搜索框 |
| 品类筛选 | 桌面左侧栏，手机原生 select |
| 结果区 | 分组折叠列表，默认全折叠 |
| 空态 | 「未找到匹配的产品链条」+ 清空筛选 |

准入门槛只在首页展示；目录页页脚「浏览 → 准入门槛」跳到首页 `#thresholds`，不重复渲染整段材料清单。关于我们与联系我们同样只在首页展示，页脚提供首页锚点入口。

### 3.3 我要合作咨询

全站常驻「我要合作」入口：桌面右下角悬浮胶囊，手机底部固定操作条。点击打开原生 dialog 表单，字段沿用参考稿：公司名字、供应链品类、单月需求、目前发票额度、联系人、联系电话、同意声明；不包含文件上传。

品类区域显示首页业务范围的前 5 个主推大类（机器人、无人机、科技链条、可变品、可定制），第 6 个胶囊为「我要定制」，展开 300 字文本框让客户填写想要的链条。前 5 个胶囊支持多选，也可以直接在输入框手写品类或链条。

提交走 `POST /api/consult.php`：服务端校验后追加写 `consult-data/consultations.csv`，再通过企业微信群机器人发送通知。CSV 一行一条，包含提交时间、编号、公司、联系人、电话、品类、定制链条、需求、发票额度、来源页面、通知状态。不引入数据库，不引入 Node 常驻进程。

## 4. 检索规则

命中范围是**链条名 + 别名 + 隐藏检索词「链条」**。展示名已不带「·链条」后缀，匹配时仍把「链条」算进去，旧写法继续有效。别名是同一实体的其他中文叫法，只参与匹配不显示。

这条规则解决的是真实问题：客户嘴里说的是「螺纹钢」，我们目录里写的是「钢材（含螺纹钢）」；客户说「塑料粒子」，我们写「PE聚乙烯（塑料）」；客户说「中草药」，我们写「中药材」。

匹配前统一归一化：去掉空白、`.` `·` `•` `-` `/` `、` `,` 这类分隔符，英文字母转小写。所以：

- 「玉米」「玉米.链条」「玉米·链条」都只命中同一条
- 「螺纹钢」命中「钢材（含螺纹钢）」
- 「塑料粒子」「低密度聚乙烯」都命中「PE聚乙烯（塑料）」

品类与关键词取**交集**：选了新能源再搜「玉米」，结果是 0 条并显示空态，不会串到农副产品。

中文输入法组合期不触发过滤，确认后才更新。

## 5. 主题

- 首次访问固定浅色，**不读**系统深色偏好
- 手动切换后写入 localStorage，跨页与刷新保持
- 存储在 `<head>` 内联脚本里同步读取并设置，避免首帧闪白
- 存储不可用或值非法 → 回退浅色，当页仍可切换
- 开关是原生 button，带 `aria-pressed` 与可读名称，键盘可达

## 6. URL 约定

| 参数 | 含义 | 缺省/非法时 |
| --- | --- | --- |
| `category` | 品类 id，如 `agri` | 视为全部分类 |
| `q` | 关键词，URL 编码 | 视为空 |

逐字输入用 `replaceState`，不堆历史。全清后移除空参数。折叠状态与主题不写进 URL。

## 7. 不做的事

数据库、账户体系、后台管理页面、文件上传、交易、产品详情页、轮播、任何虚构案例/数字/背书、AI 算力与定制软件开发（特殊渠道，本期不纳入）。咨询表单只收集业务对接所需的文字信息。
